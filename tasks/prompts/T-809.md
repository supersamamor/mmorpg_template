### Goal
Staff do the everyday moderation and support work in the panel with pages made for it, not the general command form: ADR-002 row 387 (1) and row 412 (1).

### Requirements
1. **Account page**: the account's bans, mutes and support requests (T-806's reads), with Ban, Unban, Mute, Unmute, Kick and the support-queue actions (open a deletion or export request, complete, cancel) beside them, each only for the roles the server's command list allows (the server still decides).
2. **Character page**: give and remove items (an item picker from the content the panel already reads, quantity; remove by entry from the character's saved state), give and take currency, unstick; the staff-made item changes T-806 reads. Show the command's answer (`done` with the audit row, `accepted`, or the refusal in words from `ErrorWords`).
3. **Server page**: announce (with the 80-character limit shown as you type) and maintenance on and off, for the roles allowed.
4. **Chat reports page**: open reports first, then closed; the reported line, channel, both times, sender and reporter looked up by id to names and linked to their pages; Close with a reason; Mute and Ban the sender from the same view. A clear note on the page: the line is personal data and must never be copied into a reason.
5. **Export**: a data export request's result is offered as a JSON download to staff with the right role, never kept by the panel, and the download is audited by the server's own command (no new endpoint).
6. **Every write** keeps T-805's rules: a reason, a confirmation showing the exact JSON, sent once (one-time ticket), "may have happened" when the answer is lost.
7. **Reasons**: every reason field says, next to it, to describe what happened and never to write a name, an e-mail address or anything else about a person (STORE_COMPLIANCE.md §6).
8. **Tests** against the fake admin server: each page renders what the reads return, hides actions a role cannot use, sends exactly the confirmed JSON once, shows each refusal's words, and the reports page never puts the line into a reason. Keep the existing panel tests green.
9. **Docs**: ADMIN_PANEL.md (the pages), ADR-002 rows from 490, row 387 and 412 items marked done where they are.
