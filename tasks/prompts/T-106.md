### Goal
Given attacker and defender stat snapshots plus an attack descriptor (auto-attack or skill damage effect), resolve hit/miss, crit, element multiplier, size/race hooks, and final damage — deterministically with injected RNG.

### Scope — files you may create or change

### Requirements
1. `CombatResolver.Resolve(AttackContext) → AttackResult { Hit, Crit, Element, Multiplier, Damage, Breakdown }`.
2. All math via formulas.yaml: hit chance, crit chance, physical damage, magic damage. Element multiplier from `elements.yaml`.
3. `Breakdown` is a list of named steps (base, def reduction, element ×, crit ×, final) — essential for debugging balance and for the `stats` report.
4. Minimum damage rule and clamping come from `balance.yaml`.
5. `IRandom` seeded implementation; same seed → identical results.
6. Tests: guaranteed hit/miss edge cases, element table lookups, crit path, seed determinism, golden damage values for sample matchups.
