### Goal
Prove on physical phones, before anything is built on it, that a Godot 4 .NET client can do what ADR-001 assumes: load `Game.Shared`, render a 3D scene within the ARCHITECTURE §9 budgets, keep a `wss` connection, and survive being backgrounded. The output is a go / no-go per platform, written into ADR-001. This is a throwaway spike, not the real client.

### Requirements
1. Pin one Godot 4 stable .NET version and record it (and its .NET target) in ADR-001.
2. The spike project references `src/Game.Shared` (its `netstandard2.1` build) and calls a type from it at runtime, showing the result on screen. This must work in the iOS build (AOT compiled, trimmed) — that is the main risk.
3. Test scene sized to the §9 budget: ground, some props, 40 skinned, animated characters (CC0 glTF models or simple rigged placeholders — no copyrighted assets), one directional light, a shadows on/off toggle. Show FPS, draw calls, triangle count and memory on screen.
4. Touch: tapping the ground raycasts to a cell and shows a marker there; pinch zooms the camera.
5. Network: a minimal echo server in `spikes/mobile-export/echo-server` (plain ASP.NET Core). The phone connects over `ws://` on the LAN (debug build) and over `wss://` (self-signed or a dev certificate is fine; document how). Measure round-trip time. Background the app for 30 s, return, and record exactly what happens to the socket on each platform.
6. Android: export an arm64 debug build and run it on a physical device. Record results with both the Mobile and the Compatibility renderer.
7. iOS: export the Xcode project, build it on a Mac, run it on a physical iPhone (state it if only a simulator was available). **If no Mac is available, mark the iOS half `Blocked` and say so. Do not report iOS results you did not measure.**
8. Write "Spike results" in ADR-001: Godot version, devices used, measured numbers next to each §9 budget, problems and workarounds, and a clear **go / no-go per platform**. If no-go, recommend the fallback from ADR-001 with an estimate of what it costs.
9. `docs/MOBILE_BUILD.md`: exact steps to install the Android SDK/JDK and Godot export templates, export and install on Android, and sign/build/install on iOS.
