### Goal
The rules in `CLAUDE.md` are enforced by machines, not memory. CI runs the same checks a human runs before merging. The compiler stops
`Game.Shared` from reading the clock or the disk. `validate` checks the YAML against the generated schemas. A new formula field can't
slip past `FormulaSources`.

### Scope — files you may create or change

- `src/Game.Tools/**`, `src/Game.Content/Validation/**`: the schema check, the rule changes in 4 and the export check in 1

### Requirements
1. **CI** (`.github/workflows/ci.yml`). Run it on push and pull request, on `windows-latest` and `ubuntu-latest`, with the SDK from
   `global.json`. Steps:
   - restore, then `dotnet build` with warnings as errors;
   - `dotnet test`;
   - `validate`;
   - `schema`, then `git diff --exit-code schemas/` to catch stale schemas;
   - `export-client --check`: add this flag if it doesn't exist. It exports to a temp folder and fails if the result differs from a
     committed reference, or prints the hash when nothing is committed yet. Document which.

   Cache NuGet. Set `lfs: false` on checkout, because no step needs binary art.
2. **Rule 8 by compiler.**
   - Add `Microsoft.CodeAnalysis.BannedApiAnalyzers` to `Game.Shared` with a `BannedSymbols.txt`. Ban `DateTime.Now`, `DateTime.UtcNow`,
     `DateTimeOffset.Now/UtcNow`, `new System.Random`, `Random.Shared`, `Environment.TickCount`/`TickCount64`, `Guid.NewGuid`,
     `System.Diagnostics.Stopwatch`, and the `System.IO.File`/`Directory` types. Each entry gets a message pointing at `IClock`/`IRandom`.
   - Set `IsAotCompatible` and the trim analyzers on the `net10.0` target, with warnings as errors.
   - Fix anything they find. If a fix would change behaviour, stop and report it instead.
3. **Package versions.** Bump every package in `Directory.Packages.props` to its current stable version (`dotnet list package --outdated`).
   Stay within the same major version, except where a major version has no breaking change for us; say which.
4. **Validation.**
   - **Schema check:** `validate` also checks each YAML document against its `schemas/*.schema.json`, so editor and runtime can't disagree.
     Pick a maintained, reflection-light JSON Schema library for the tool side only; `Game.Shared` must not reference it. Report schema
     errors with file, line and path, like the other rules.
   - **Unused-skill warning:** `UnusedRule` counts a monster's `ai.skills` as a use of the skill, so `skill.venom_sting` stops warning.
   - **Spawn and placement warnings:** new warnings for a monster no grid spawns, and an NPC no grid places.
   - **Modifier warning:** a percent modifier whose constant value is ≤ −100.
   - New codes go in `ValidationCodes` and VOCABULARY.md if it lists them.
5. **Formula marker.** Add a `[Formula]` attribute in `Game.Shared` (no reflection at runtime) on every formula-string property. Add a
   test that uses reflection over all definition records and fails when a property marked `[Formula]` is not returned by
   `FormulaSources`, or a `FormulaSources` path has no marked property.
6. **Tests.**
   - **Stats command:** an end-to-end test of the `stats` command (reference `Game.Tools` from the tests, or move the logic into
     `Game.Content`; say which).
   - **Time to kill:** add time-to-kill in seconds to the `stats` report (`aspd` is attacks per second), with the golden snapshot
     regenerated on purpose.
   - **Non-parallel collection:** move every test that measures wall time or allocations into one `DisableParallelization` collection.
     That includes the `AllocationProbe` users, the budget tests and the gateway rate-limit tests.
