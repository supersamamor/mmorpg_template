### Goal
A deterministic stat calculator: base stats + sourced modifiers → final primary stats → derived stats via formulas. Supports adding/removing modifiers by source.

### Scope — files you may create or change
- `src/Game.Shared/Stats/**`
- `tests/Game.Tests/Stats/**`

### Out of scope — do not touch
- Equipment/inventory systems (Phase 4) — just accept modifiers with a source id

### Requirements
1. `StatBlock` holds base primary stats. `ModifierSet` holds modifiers tagged with `SourceId` (e.g. `equip:weapon`, `status:status.blessing`).
2. Evaluation order per ARCHITECTURE §5.1: `(Base + ΣFlat) × (1 + ΣPercent)`, then `override` wins; document rounding (floor at the end).
3. Derived stats computed from `formulas.yaml` using final primary stats + level context. Derived stats can also receive modifiers (e.g. `+10 atk` from a weapon).
4. Cache results; invalidate on modifier add/remove or base change. Expose a `Version` counter for change detection.
5. `RemoveBySource(sourceId)` is O(modifiers).
6. Tests: flat+percent stacking, removal restores exact prior values, override precedence, derived stats match hand-calculated golden values for 3 sample characters.
