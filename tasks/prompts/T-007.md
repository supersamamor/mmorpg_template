### Goal
Today, after `setup-prereqs.ps1` runs, someone still has to open Android Studio, install SDK packages and accept the licences by hand.
The script should do that part itself whenever the SDK command-line tools are present.

### Scope
- `setup-prereqs.ps1`, `README.md`, `docs/MOBILE_BUILD.md` (the manual-steps section), `docs/TASKS.md` (this row only)

### Requirements
1. **Install the pinned packages.** After the installs, look for `sdkmanager` under `%LOCALAPPDATA%\Android\Sdk\cmdline-tools\latest\bin`.
   If it is there:
   - install exactly the packages `MOBILE_BUILD.md` pins: platform android-35, build-tools 35.0.1, platform-tools;
   - accept the licences non-interactively;
   - use the JDK 17 the script installed (`JAVA_HOME` for that process only).
2. **Missing command-line tools.** If they are absent (Android Studio not opened yet), print one clear step to install them through
   Android Studio's SDK Manager, then re-run the script. Don't download the tools from an unpinned URL.
3. **Re-runs.** It is safe to run twice: packages already installed are skipped, and a second run makes no changes.
4. **Parameter.** Add a `-SkipAndroid` switch.
5. **Docs.** Update the manual-steps list in the script output, `README.md` and `MOBILE_BUILD.md` so they stay in agreement.
