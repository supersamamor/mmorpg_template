### Goal
`Game.Tools schema` generates one JSON Schema per definition type from the C# records into `/schemas`, so editors (VS Code YAML extension) give autocomplete/validation while writing content.

### Scope — files you may create or change
- `src/Game.Tools/Commands/SchemaCommand.cs`
- `src/Game.Content/Schema/**`
- `/schemas/*.schema.json` (generated, committed)
- `.vscode/settings.json` (yaml.schemas mapping)
- `tests/Game.Tests/Schema/**`

### Out of scope — do not touch
- Changing definition records (if one needs changing, list it in your reply)

### Requirements
1. Use `System.Text.Json.Schema.JsonSchemaExporter` (.NET 9+) with snake_case naming to match YAML keys.
2. Inject `description` from XML doc comments where feasible; inject `enum` constraints from Vocabulary sets for fields like effect `type`, `element`, `slot`, `stat`.
3. Add `pattern` constraints on id fields per prefix (e.g. `^item\.[a-z0-9_]+$`).
4. Output `schemas/<type>.schema.json`, deterministic ordering (stable diffs).
5. Map schemas to globs in `.vscode/settings.json`, e.g. `content/items/**/*.yaml` → `schemas/item.schema.json`.
6. Test: generated schema for `ItemDef` contains the id pattern and the `kind` enum.
