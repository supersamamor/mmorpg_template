### Goal
A compiling .NET 10 solution matching the layout in ARCHITECTURE.md §2, with shared build settings, central package management, and an empty-but-running test project. No game logic yet.

### Requirements
1. Target `net10.0`; `Nullable` enable, `ImplicitUsings` enable, `TreatWarningsAsErrors` true, `LangVersion` latest — set once in `Directory.Build.props`.
   **Exception — `Game.Shared`:** `<TargetFrameworks>net10.0;netstandard2.1</TargetFrameworks>`, `LangVersion 9.0`, `ImplicitUsings disable` (the Godot client on Android/iOS runs an older .NET runtime and must reference it — see ARCHITECTURE.md §2 and ADR-001; T-005 tests this on devices). Add `src/Game.Shared/Polyfills/IsExternalInit.cs` (internal, `#if NETSTANDARD2_1`) so records/`init` compile.
2. Central package management via `Directory.Packages.props`. Add: `YamlDotNet`, `xunit`, `xunit.runner.visualstudio`, `Microsoft.NET.Test.Sdk`, `FluentAssertions` (or `Shouldly` if FluentAssertions licensing is a concern — state which and why), `System.CommandLine` for the CLI.
3. Project references exactly: Content→Shared; Server→Shared,Content; Tools→Shared,Content; Tests→Shared,Content. **Game.Shared references nothing in the solution and no I/O packages.**
4. `Game.Server` is a console app with a placeholder `Program.cs` that logs `Server starting` and exits.
5. `Game.Tools` is a console app using System.CommandLine with stub commands `validate`, `schema`, `stats` that print `not implemented` and return exit code 2.
6. One smoke test in `Game.Tests` that asserts true, so the pipeline is proven.
7. `global.json` pins the installed .NET 10 SDK feature band with `rollForward: latestFeature`.

### Acceptance criteria
- [ ] `dotnet build` passes with zero warnings (`TreatWarningsAsErrors` on)
- [ ] `dotnet test` passes
- [ ] `dotnet run --project src/Game.Tools -- validate` prints `not implemented` and exits 2
